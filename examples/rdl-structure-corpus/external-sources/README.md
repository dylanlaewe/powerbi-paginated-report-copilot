# External-source discovery

This directory contains discovery metadata only. It is separate from the personally authored controlled fixtures.

- Controlled fixtures are authored by Dylan and stored under their fixture `source/` directories.
- External compatibility candidates are upstream-authored reports that may be proposed for a later reviewed import.
- Imported external sources would be copied into a future explicitly authorized location with pinned identity and attribution.
- Gate 2D imports no external `.rdl` and creates no external `source/` directory.

The Microsoft Reporting Services assessment is in `microsoft-reporting-services/`.
